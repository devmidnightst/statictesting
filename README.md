# statictesting

One SVG per page. The SVG is the jsDelivr entry. Styles, scripts, and proxy URLs load from https://nocturne.lol so the sidebar still works when `cdn.jsdelivr.net` cannot be reached for those files.

Use tag `v1.0.1`:

- https://cdn.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.1/index.svg
- https://fastly.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.1/index.svg
- https://gcore.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.1/index.svg

If Zen says it cannot connect to `cdn.jsdelivr.net`, open the fastly or gcore link instead.
