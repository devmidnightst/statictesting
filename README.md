# statictesting

Static assets and one SVG per page. jsDelivr serves `.html` as plain text, so the pages are published as SVG.

Tag `v1.0.0` is immutable on the CDN. Examples:

- https://cdn.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.0/index.svg
- https://cdn.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.0/ai.svg
- https://cdn.jsdelivr.net/gh/devmidnightst/statictesting@v1.0.0/src/css/global.css

There are 32 page SVGs, one for each transformed HTML file. `src/img/*.svg` are image assets, not pages.
